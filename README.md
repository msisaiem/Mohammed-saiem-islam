# Mohammed Saiem Islam — GitHub Pages Portfolio

Files:
- `index.html` — complete responsive portfolio with SEO meta tags, Open Graph, JSON-LD ProfilePage/Person schema, and Google Search Console verification placeholder.
- `robots.txt` — permits crawling and points Google to the sitemap.
- `sitemap.xml` — sitemap for the portfolio homepage.

## Google Search Console
1. Open Google Search Console and add the GitHub Pages URL as a URL-prefix property.
2. Choose HTML tag verification.
3. Copy Google's verification token.
4. In `index.html`, replace:
   GOOGLE_VERIFICATION_CODE
   with the exact token.
5. Commit/push the file to GitHub.
6. Return to Search Console and click Verify.
7. Submit `sitemap.xml` in Search Console.
